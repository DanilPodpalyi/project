# Синтетические примеры

`resumes/anna_sokolova.docx` и `resumes/alexey_morozov.docx` — копии вымышленных
резюме, предоставленных автором проекта для проверки. Их происхождение
подтверждено автором; исходные документы при копировании не изменялись.

`precomputed/` содержит вымышленные JSON: маркетолог, заранее подготовленная
оценка качества и условные требования вакансий. Домены `.test` и `.example`
не являются действующими источниками рынка. Эти файлы нужны тестам и офлайн-демо.

Запуск без интернета и Ollama: `python scripts/demo.py`.
Выходной отчёт демонстрирует правила обработки, а не текущие требования рынка.
Для настоящего поиска: `python -m resume_evaluator analyze resumes.docx output/result`.

Другие старые локальные примеры находятся в `examples/legacy/` и в релиз не входят.
