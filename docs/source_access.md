# Подключение источников

Для работы нужен исходящий HTTPS к `api.hh.ru` и `opendata.trudvsem.ru`,
а также доступ к настроенному серверу Ollama. В API вакансий передаётся должность,
а не резюме. Программа читает вакансии и не публикует отклики или сообщения.

Проверка API без модели:

```powershell
python -m resume_evaluator check --sources "Графический дизайнер" --output-directory output/health
```

Команда сохраняет `source_check.json`, печатает причины отказов и возвращает 1,
если источник недоступен. Это проверка доступа, а не построение полноценного
профиля: лимиты уменьшены, релевантность описаний моделью не оценивается.

В среде разработчика HH отвечал 403, «Работа России» предоставляла вакансии.
Заказчику необходимо выполнить проверку на своём компьютере и зафиксировать
`source`, `stage`, `http_status`, `reason` из диагностики. Секреты в заявку поддержке
не передавайте. Для HH укажите идентифицирующий User-Agent с контактом приложения.
Если требуется авторизация, оформите приложение и получите действующий токен
по официальной инструкции, затем задайте `HH_ACCESS_TOKEN` через окружение.
403 может иметь разные причины; токен не гарантирует исправление ограничения.

Документация площадки: [авторизация HH](https://github.com/hhru/api/blob/master/docs/authorization.md),
[общие правила HH](https://github.com/hhru/api/blob/master/docs/general.md),
[ошибки HH](https://github.com/hhru/api/blob/master/docs/errors.md),
[API «Работа России»](https://trudvsem.ru/opendata/api).

Для приёмки рыночных советов нужны минимум три подходящие прямые вакансии
с полными описаниями, датами за 120 дней, Россией и совместимым уровнем.
Большое число поисковых совпадений само по себе этого не обеспечивает.
Проверяется также разделение прямых и смежных ролей и независимость работодателей.

Если доступа нет, можно передать полные вакансии JSON через `--vacancies-json`.
Формат и валидация описаны в [russian_market.md](russian_market.md).
Не подменяйте живую выборку файлами из `examples/precomputed`:
это вымышленные данные для тестов и демо.
