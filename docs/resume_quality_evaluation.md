# Независимая оценка резюме

`resume_evaluator.resume_quality_evaluator` оценивает качество резюме без вакансии. Модель отдельно
анализирует опыт работы, проекты, шапку, раздел «О себе», навыки и образование.
Для каждого раздела результат содержит балл, обоснование, сильные стороны,
недостатки и рекомендации.

Запуск:

```powershell
python -m resume_evaluator.resume_quality_evaluator examples/resume.txt output/resume_quality.json
```

Поддерживаются TXT, DOCX и PDF с текстовым слоем. Используется локальная модель
Ollama `gemma4:12b`, как и в остальных модулях проекта.

Максимальные оценки разделов: опыт — 25, проекты — 20, шапка — 15,
«О себе» — 15, навыки — 15, образование — 10. Модель не возвращает итоговый
балл: после проверки границ всех шести оценок программа суммирует их и
ограничивает результат значением 100.
