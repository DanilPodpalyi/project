# Передача исходников 0.2.0

Формат поставки согласован: исходный код и инструкция запуска.
Рабочая поставка — архив из `dist/`, а не копия папки разработчика целиком.

| Область | Что подготовлено |
|---|---|
| Структура | Активные модули, legacy, research; совместимые старые импорты |
| Зависимости | Точные прямые версии, полный requirements.lock, pyproject.toml |
| Конфигурация | TOML и окружение, пример настроек, тайм-ауты, валидация |
| Источники | Проверка API и инструкция подключения; HTTP 403 остаётся внешним ограничением |
| Документация | README, конфигурация, архитектура, схемы, изменения и приёмка |
| Проверки | Существующие правила и новые сценарии сбоев, запуск из чистой установки |
| Повторный запуск | run.json, собственные папки, атомарные записи, сохранение старых результатов |
| Состав | Код, тесты и подтверждённые автором вымышленные примеры; рабочие данные исключены |

Архив содержит внутренний release_manifest.json с SHA-256 и размером каждого
файла. Рядом лежит SHA-256 архива. Сервер Ollama, модели и их веса в поставку
не включены; они устанавливаются на стороне заказчика.

Перед эксплуатацией заказчику требуется:

1. Установить по README, проверить обе модели и запись результатов.
2. Проверить доступ к HH и «Работе России» из своего окружения; при 403 —
   оформить необходимый доступ у HH по [инструкции](source_access.md).
3. Выполнить живой прогон на своей машине и проверить достаточность прямой
   выборки. Частичный отчёт является предусмотренным результатом, но не
   приёмкой полноценной рыночной аналитики для этой профессии.
4. Согласовать допустимое время и оборудование. Размер весов не определяет
   минимальную RAM/VRAM, замеры разработчика не заменяют проверку машины заказчика.
5. Зафиксировать модель/digest и версии среды вместе с приёмочным протоколом.

Оставшиеся ограничения: небольшая наблюдаемая выборка, изменчивость площадок и LLM,
отсутствие OCR/автоматического продолжения, неполная привязка старой готовой оценки
к версии документа (проверяется имя, SHA-256 входов записан в run.json).
Эти ограничения описаны в инструкции; они не маскируются вымышленной выборкой.

Сведения о выполненных проверках и фактическом результате нового прогона:
[release_acceptance.md](release_acceptance.md).
