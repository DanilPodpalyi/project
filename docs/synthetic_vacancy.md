# Синтетическая эталонная вакансия

Модуль `synthetic_vacancy_pipeline.py` строит эталонную вакансию по
структурированному резюме. Результат совместим со схемой `VacancyData` и может
передаваться непосредственно в `candidate_scorer.py`.

## Запуск

Сначала извлеките резюме:

```powershell
python -m resume_evaluator.resume_extractor `
  examples/resume.txt `
  output/resume.json
```

Затем постройте эталонную вакансию:

```powershell
python -m resume_evaluator.synthetic_vacancy_pipeline `
  output/resume.json
```

По умолчанию результат сохраняется в `synthetic_vacancy.json`. Другой путь
можно передать вторым позиционным аргументом.

```powershell
python -m resume_evaluator.synthetic_vacancy_pipeline `
  output/resume.json `
  output/synthetic_vacancy.json
```

## Этапы

1. Локальная модель определяет целевую профессию и 3–5 поисковых запросов.
2. Публичные API Jobicy, JobsCollider, Remote OK, Remotive, Arbeitnow и hh.ru
   возвращают актуальные вакансии. Ошибка одного источника не останавливает
   остальные; после получения достаточного пула лишние запросы не выполняются.
3. Pipeline требует не менее 20 уникальных актуальных вакансий, удаляет
   дубликаты по URL и паре «название + работодатель».
4. Локальная модель извлекает факты и помечает нерелевантные вакансии.
5. Python-код рассчитывает косинусную схожесть нормализованных профессий,
   навыков и обязанностей, затем выбирает тройку с лучшей комбинацией
   релевантности кандидату и взаимной схожести.
6. Модель группирует только переданные исходные формулировки. Код отклоняет
   выдуманные элементы, считает частоты и строит итоговую вакансию.

Навык с частотой 2–3 попадает в `required_skills`, с частотой 1 — в
`preferred_skills`. Опыт рассчитывается как медиана явно указанных минимальных
значений. Обязанности сохраняются только при наличии одной смысловой группы
минимум в двух выбранных вакансиях.

## Проверяемость результата

Расширенные поля не мешают `VacancyData` и `candidate_scorer.py`:

- `selected_vacancies` — выбранные три вакансии и их ссылки;
- `requirement_evidence` — частота, ссылки и исходные варианты навыка;
- `responsibility_evidence` — доказательства повторяющихся обязанностей;
- `experience_evidence` — значения опыта и ссылки;
- `other_requirement_evidence` — частоты и ссылки для медианного опыта,
  образования, занятости и формата работы;
- `pipeline_statistics` — запросы, количества и ошибки источников.

Полное резюме не передаётся сайтам вакансий. В интернет уходят только
поисковые запросы. Тексты резюме и вакансий обрабатываются локальной Ollama.

Для авторизованного hh.ru можно задать `HH_ACCESS_TOKEN`; идентификатор клиента
берётся из `HH_USER_AGENT`. Секреты не следует сохранять в репозитории.
