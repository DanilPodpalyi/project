JSON резюме, оценки и рынка. С прежним бюджетом 1800 секунд он остановился через

Второй запуск явно использовал эти три артефакта и соответствующую коллекцию;

Офлайн-демо на вымышленных JSON не заменяет живые API-запросы этого прогона.
На машине заказчика требуется собственная проверка времени и доступности источников.

## Повторение приёмки

1. Распаковать ZIP в новую папку, создать пустой venv и установить requirements.lock.
2. Установить пакет: pip install --no-deps --no-build-isolation .
3. Выполнить pip check, check, unittest discover -s tests и два запуска scripts/demo.py.
4. Проверить модели, запись в output и API источников из среды заказчика.
5. Запустить analyze на синтетическом DOCX и проверить прямую выборку/источники.
6. Сверить внутренний manifest и SHA-256 архива.

Полноценные рыночные выводы принимаются только при достаточной прямой выборке;
малочисленный рынок должен оставаться partial и не заполняться фиктивными советами.
Логи разработчика в output/ не включены в поставку, тестовые данные из examples/ вымышленные.
